# Wournal Extension

Wournal is a lightweight browser extension for saving text from the web so you can access it later. It is currently under development.

## Installation

1. Download the latest release `.zip` from the [Releases](https://github.com/davoodrb/wournal-the-extension/releases/) page.
2. Extract the `.zip` file.
3. Load the extension in your browser (e.g., Chrome: `chrome://extensions` → Enable Developer Mode → Load Unpacked → Select extracted folder).

## Usage

1. Select any text on a webpage.
2. Right-click and choose **Add to Wournal**.
3. Open the extension to view all your saved snippets.
